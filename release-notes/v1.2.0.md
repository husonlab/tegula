# Tegula 1.2.0

First release of Tegula built from the Maven-based sources and distributed through the shared
installer pipeline. Tegula displays and explores two-dimensional periodic tilings, represented by
Delaney–Dress symbols, in spherical, euclidean and hyperbolic geometry.

## New features

- Help menu with Check for Updates..., About... and Open User Manual in Browser...
- User manual, published at https://husonlab.github.io/tegula
- File -> Download... fetches a database of tilings, expanding it as it arrives and remembering where
  it was put. The program offers to do this on its first start, so that a fresh installation has
  something to show without the user having to find the data themselves
- Reshaping of the fundamental domain is now kept when a rotational symmetry is changed, so that a
  reshaped tiling can be carried from one geometry into another
- Hyperbolic tilings are shaded as the disk they are drawn as, rather than from the unbounded
  hyperboloid their points lie on, which removes the spotlight-like darkening towards the rim
- Curved surfaces are shaded from the surface rather than per triangle, so that they no longer read
  as a set of facets

## Bug fixes

- Fixed the dark ring around spherical tilings under point lighting, caused by materials whose
  specular colour was left unset
- Fixed a fundamental-domain node restricted to a mirror line jumping to the centre when dragged, in
  spherical geometry
- Fixed the Save As dialogs offering file names with a doubled suffix
- Semi-transparent spherical tilings now show the far side through the near one, instead of the far
  tiles disappearing
- Fixed a freshly opened collection showing a single tiling per page until the window was resized

## Known issues

- With semi-transparent tiles, the far side of a sphere is only visible when Backs is switched on
- Very faint facet structure remains in the middle of a hyperbolic tiling under point lighting
