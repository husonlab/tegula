# Tegula

Tegula is an interactive desktop application for exploring periodic tilings of the three
two-dimensional geometries: the sphere, the euclidean plane and the hyperbolic plane. Tilings are
represented by Delaney–Dress symbols, which lets them be enumerated, stored in databases and browsed
by the million.

Open source repository: https://github.com/husonlab/tegula
